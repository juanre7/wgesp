wgesp — flasher web para ESP32-C6

Conecta el ESP32-C6 por USB y pulsa el boton. Ni toolchain, ni esptool, ni drivers.

  1. 1 Conectar
  2. 2 Flashear
  3. 3 Configurar
Este navegador no soporta Web Serial. Abre la pagina en Chrome, Edge u Opera de escritorio. El flasheo necesita HTTPS.

Chrome · Edge · Opera  —  solo escritorio

01 / CONECTAR

Sin drivers

El C6 usa su USB nativo. Windows 10+, macOS y Linux lo reconocen solos.

En Linux tu usuario tiene que estar en dialout o el puerto no aparece.

02 / FLASHEAR

Imagen completa

Borra la flash y escribe bootloader, tabla de particiones y aplicacion.

Alrededor de un minuto. No desconectes el cable mientras avanza la barra.

03 / CONFIGURAR

Claves y WiFi

La placa arranca vacia. Vuelve a pulsar el boton y abre Logs & Console.

Se guarda en NVS: sobrevive a un reinicio, no a un borrado de flash.
